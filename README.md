# Bass Studio 🎸

Bas gitaristler için Meta Demucs AI destekli stem ayrıştırma (Vokal, Bas, Davul, Enstrüman), şarkı trafiği, akor ve BPM analiz istasyonu.

## Özellikler
- 🎸 **AI Stem Separation:** Yüklenen şarkıyı vokal, bas, davul ve enstrüman kanallarına ayırma.
- 🥁 **Groove & Ritim Odaklanma:** Bas ve davulu yalnızlaştırarak groove çalışabilme.
- 🚫 **Backing Track / Bas Mute:** Şarkıdaki bası kapatıp üzerine çalabilme.
- 📊 **BPM & Key Detection:** Şarkının temposunu, tonunu ve bas gam önerilerini çıkarma.
- 🚦 **Şarkı Trafiği & Akorlar:** Intro, Verse, Chorus, Bass Solo trafik şemaları ve kök notalar (Root Notes).

## Kurulum & Çalıştırma
```bash
pip install -r requirements.txt
streamlit run app.py
```
